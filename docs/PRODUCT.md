# Product and positioning

**One chat to command all your AI agents. One canvas to orchestrate them.**

Confignostic is a universal control layer for existing independent agents, not a proprietary agent framework. Intended early users are small development teams using multiple coding agents.

## Essential experiences
1. Direct a task at a selected connected agent or address one with an @mention.
2. Ask the orchestrator to propose multi-agent tasks and their dependencies.
3. Review and edit those dependencies on a visual DAG canvas.
4. Stream status, outputs and artifacts into a single execution timeline.
5. Self-host or purchase a managed cloud workspace with optional private runners.

## Initial exclusions
Model hosting; legacy IDE configuration migration; uncontrolled remote administration; new AI model infrastructure; pretending that different providers all expose the same session APIs.

## Pilot acceptance
Dispatch a real agent task from chat, persist its execution through a restart, hand structured output to a second independent provider, truthfully display failure, and require approval for high-impact actions.

## Commercial hypothesis
Full chat, connectors and workflow canvas remain self-hostable in open source. Paid cloud sells hosting, team collaboration, operations, service reliability and support. Provider usage fees remain separate.
