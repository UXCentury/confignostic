# Product roadmap

## Phase 0 — validate
Interview ten teams using two or more agent systems; ask for workflows, pain points, existing workarounds, and payment willingness.

## Phase 1 — one real agent
Connect one provider. Chat starts real tasks and shows real results. Persist task history, handle errors, and prove state recovery after restart.

## Phase 2 — coordinate independent agents
Add another provider, typed output handoffs, sequential execution, approvals and safe retries. Demonstrate task → implementation → independent review.

## Phase 3 — shared visual canvas
Editable validated workflow DAG with parallel steps, conditions and error paths. The same workflow representation is used by the chat orchestration mode.

## Phase 4 — cloud experiment
Hosted control plane, accounts, teams, billing, logs, production security, private runners and real paid pilots.

Avoid IDE plugins, model hosting, generic device administration, and enterprise features without paying demand.
